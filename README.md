A Python program that writes one funny line — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`, for make.fun's "One-Liner Laugh Lab" bounty. The line: a deadpan excuse that reframes the act as a rescue — the sock was single, face-down on the floor at 2 a.m., clearly going through something, so the vacuum did what any vacuum would do and took it home.

## Run it

```sh
python3 main.py
```
